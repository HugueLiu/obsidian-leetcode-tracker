# LeetCode Tracker

Obsidian 插件。把 leetcode.cn 的刷题记录拉到本地，并且能**重置**——重置靠抬高一条时间线实现，旧记录原样留在本地。

## 它解决什么

力扣上「通过过」只有成功这一个事实，什么时候通过得自己另存一份。真正要区分的是：哪些题**几年前刷过、这轮还是空白**，哪些是**这一轮新做的**。所以重置只是记一个时间点，之后按这个点重新分类，提交记录全部原样保留。

## 判定规则

每题的状态由四层依次判定，前面的命中就停：

1. 手动标过「未刷」 → 未刷
2. 手动标过「已刷」 → 已刷
3. 最后一次 AC 晚于本题的重置线 → 已刷
4. 早于重置线：有 AC 记录 → **以前做过**，否则 → 未刷

重置线按题取 `max(本题重置线, 全局重置线)`。重置可以叠加，提交记录全部保留，所以随时能看出「这题一共通过过几次」。

## 安装

把 `main.js`、`manifest.json`、`styles.css` 放进：

```
<vault>/.obsidian/plugins/leetcode-tracker/
```

重启 Obsidian，在「第三方插件」里启用。

## 用法

### 登录

设置 → LeetCode Tracker → Cookie。两种方式：

- **内嵌登录**：点「打开登录窗口」，在弹窗里登录力扣，成功后自动取走 cookie 并验证
- **手动粘**：F12 → Network → 任一 graphql 请求 → 复制整条 Cookie 粘进去。只取 `LEETCODE_SESSION` 与 `csrftoken`，其余忽略

顶部显示用户名和头像；未登录是灰点，cookie 失效会提示「登录已过期」。

### 同步

| 操作 | 做什么 | 耗时 |
|---|---|---|
| 同步题库 | 拉全量题目列表，每天一次即可 | ~40 秒 |
| 同步提交（增量） | 只拉上次之后的新提交，撞到上次游标就停，上限 1200 条 | ~1 秒 |
| 全量对齐 | 逐题查一遍提交历史，补齐被接口 2000 条窗口截掉的旧记录 | ~15 分钟 |

默认每 5 分钟自动增量一次，可在设置里改间隔或填 0 关闭。

> 全量对齐只在「某题明明做过、本地却缺几条」时用。平时增量就够。

### 三个页面

- **主面板**：列表 + 四个 tab（全部 / 本轮未做 / 已刷 / 以前做过）。数字自带口径：`已刷 + 本轮未做 = 全部`，`以前做过` 是 `本轮未做` 里需要重刷的那部分。行尾的「12 条」是入口，点一下就地展开这题的提交历史；点击行弹出菜单（重置此题 / 标记为已刷 / 撤销重置 / 在力扣打开）
- **提交记录页**：按提交时间的流水，一行一次提交，点行跳力扣
- **看板**：本轮/累计已刷、连续天数、热力图、月度提交、难度双轨对比、结果分布、高频标签、最近提交

### 轮次

每次「重置全部」产生一个新轮次。顶部下拉可以在「最新状态」和各轮之间切换，看当时那一轮结束了多少题。

### 重置

- 单题：行菜单里的「重置此题」，之后可以在同一菜单「撤销本题重置」
- 全部：设置页的「重置全部」（连点两次确认），或命令面板 `LeetCode Tracker: 重置全部题目为未刷`
- 撤销：设置页「撤销全局重置」把全局线改回 0，所有历史通过重新计入

## 数据

都在 vault 内的 `.leetcode/`，纯 CSV，可以直接用 Excel 看：

| 文件 | 内容 |
|---|---|
| `problems.csv` | 题库，4498 行（题号、slug、双语标题、难度、通过率、标签、是否会员题） |
| `records.csv` | 每条提交一行（id、slug、状态、语言、时间、耗时、内存、来源） |
| `ac-slugs.csv` | 力扣确认通过过的题，998 行 |
| `events.csv` | 重置事件，轮次由它投影出来 |

`data.json` 在插件目录下，存设置和 cookie，属本地配置。

## 已知限制

- 「重置全部」同时清空手动标的已刷与未刷，两项一起归零
- 提交记录页按提交时间流水展示，单题历史在主面板展开
- 看板为只读视图，筛选操作在主面板进行
- 轮次只支持往后新建与切换，回退到第 N 轮暂未实现
- 力扣接口单页最多 40 条、全局 offset 上限 2000，所以全量对齐是按题逐道查的
- 改完代码要在设置里把插件关掉再开，重开面板时插件仍用旧代码

## 开发

```bash
npm install

npm run build    # 生产构建
npm test         # 77 项断言
```
